# 学术笔记 profile（论文精读稿专用）

本 profile 是 stop-slop-zh 在这个 Obsidian 论文库里的落地版本，适用于 `papers/@*.md` 文献笔记和 `papers/bilingual/*_中英混读.md` 精读稿。

母 skill 的默认设定是公众号长文，硬禁小标题、bullet、编号结构。论文精读稿的骨架由本库根目录的 `AGENTS.md` 规定，不能拆。所以这里做一次分层，骨架听 AGENTS.md，中文散文听 stop-slop-zh。

## 分层规则

| 层 | 归谁管 | 说明 |
|---|---|---|
| 文件骨架 | AGENTS.md | 必需章节、章节顺序、逐节展开、矩阵表格，照写不改 |
| 表格、公式、代码块、YAML frontmatter | AGENTS.md | 里面的冒号、引号、破折号都是语法，不算命中 |
| 英文原文、论文标题、术语、指标名 | 保持原样 | `English（中文）` 格式保留，不做中文化改写 |
| 中文解释性散文 | stop-slop-zh | 禁用词、禁用标点、活人感全部生效 |

## 冒号在这里怎么算

只统计**中文正文句子里**的冒号。以下位置的冒号不计入 L1 命中数。

- YAML frontmatter 的 `key: value`
- Markdown 表格分隔行和单元格里的英文原文
- LaTeX 公式、代码块、文件路径、URL
- Figure 3: 这类原文图题编号

中文句子里用冒号引出解释、定义、列举，一律改掉。写成`核心思路是……`，不写`核心思路：……`。

## 双引号在这里怎么算

英文原文引用（论文原句、术语、模型名）保留英文双引号。中文里标注概念一律用「」。

## 编号结构在这里怎么算

论文本身的章节编号（Section 3.2、Stage 1/Stage 2/Stage 3）是原文事实，照抄。

禁的是写作者自己造的编号腔，比如`第一，模型做了 X。第二，实验证明 Y。第三，作者认为 Z`。这种改成自然过渡。

## bullet 在这里怎么算

允许的 bullet 是**信息清单**，比如数据集列表、超参、基线名、指标数值、图表线索。

不允许的 bullet 是**把论证拆成三条并列短句**。方法怎么work、为什么这么设计、证据强不强，这些要写成连贯段落，不许用 bullet 逃避解释。

判据是，把这个 bullet 列表读出来，如果听起来像在念提纲，就该改成散文。

## 加粗

母 skill 限全文 10 处。精读稿长，放宽到每个大节不超过 3 处，且只加粗真正的判断句和关键数值，不加粗术语（术语已经有 `English（中文）` 形式做视觉锚点）。

## 语气校准

精读稿不是公众号，不要硬塞`太离谱了``给人整不会了`这类情绪词。推荐词组库里可以用的是判断类和承认类。

- 判断类，说到底、可以确定的是、不在一个尺度上、值得画出来
- 承认类，说实话也不确定、这里作者没给证据、还在摸索、踩过坑
- 拉近类，很多做 VLA 的会遇到、大家也都知道

母 skill 要求全文 8-10 个口语化词组，这里降到 4-6 个，且必须出现在`我的阅读判断``局限与可追问点``精读路线`这类需要作者出面表态的段落，不要撒在方法描述里。

## 精读稿最需要防的三种 AI 味

**平铺直叙的转述**。逐句翻译摘要不算精读。每节要说清楚这节在全文论证里干什么活，作者为什么非得加这一步。

**无差别肯定**。论文说什么就跟着说什么，不标注哪些结论证据薄。实验只跑了两个 benchmark 就要说出来，提升 3 个点也要说出来。

**万能句填充**。`该方法在多个基准上取得了显著提升`这种句子等于没写。要么给数字，要么给对比对象，要么删掉。

## 适用范围

在管的是内容文件，`papers/bilingual/*_中英混读.md`、`papers/@*.md` 的中文段落、`论文地图.md` 里的 `map_brief` / `map_role`，以及 agent 给用户的汇报文字。

不管规格文件。`AGENTS.md`、`CLAUDE.md`、`.gitignore` 注释、脚本 docstring 属于规格与配置，沿用它们各自已有的写法，扫出命中不算问题，不要去改。

## 质检脚本

`setting/scripts/check_zh_style.py` 是 L1 的机器实现，扫描时会自动剥掉 frontmatter、表格、代码块、公式块、图片嵌入和 wikilink，只查中文散文。

```bash
python setting/scripts/check_zh_style.py papers/bilingual/<新稿>_中英混读.md
```

命中不为 0 就返工再交。2026-08-16 之前写的 30 篇旧稿未经此规则，扫描会报大量命中，不要求回改。
