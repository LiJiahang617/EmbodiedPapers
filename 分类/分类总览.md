# 分类总览

这里是 Zotero 式的集合入口。每篇文献笔记的 frontmatter `tags` 里挂了 1 到 4 个 `cat/...` 标签，一篇论文可以同时属于多个分类，比如 WAM-RL 同时在 WAM 和 RL 两个集合里。点下表任何一个分类页，Dataview 会自动列出该方向的全部论文，不需要手工维护清单。左侧标签面板里展开 `cat` 按标签浏览，效果相同。

新论文入库时从下表选分类打标签，确实放不进任何一类再新开分类，新开时在 `分类/` 下建对应页面并让它带上 `cat` 与 `desc` 字段，本页的表会自动收录。细粒度的单篇定位仍看 [[论文地图]] 的快速索引。

```dataviewjs
const cols = dv.pages('#collection').where(p => p.cat).sort(p => p.file.name);
const papers = dv.pages('#paper').array();
dv.table(["分类", "范围", "篇数"], cols.map(c => {
  const tag = "#" + c.cat;
  const n = papers.filter(p => (p.file.etags?.array?.() ?? p.file.etags ?? []).includes(tag)).length;
  return [c.file.link, c.desc, n];
}));
```
