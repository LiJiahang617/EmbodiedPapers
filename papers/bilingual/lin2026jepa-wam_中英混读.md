# JEPA-WAM: Learning Vision-Language-Action Policies with Joint-Embedding World Modeling

paper:: [[@lin2026jepa-wam]]
pdf:: [[papers/pdfs/lin2026jepa-wam.pdf]]
images:: [[papers/images/lin2026jepa-wam/index.md]]

## 一句话总结

这篇论文在构造一个不生成未来帧的潜空间世界动作模型（latent WAM），核心是两个设计答案，预测目标用冻结 V-JEPA 联合编码当前帧与未来帧得到的「联合当前-未来目标」（保留 patch 级空间结构，编码的是转移关系而非绝对未来），监督位置用一个与动作生成共享的预测器（Qwen2.5-0.5B），让转移监督直接塑造产生动作表示的那个骨干。0.5B 骨干在 LIBERO-Plus 上拿到无机器人预训练组最好的 79.2%，同一套监督加到预训练 π0.5 上拿到全场最好的 86.3%，部署时预测分支整个摘掉。

## 摘要

鲁棒的机器人控制受益于显式建模状态转移，但视频生成式 WAM 带来可观的部署成本。现有潜空间 WAM 避开了显式未来生成，却常常压缩预测表示，或把预测建模与动作生成所用的表示分开。作者提出 JEPA-WAM，一个建在预训练 V-JEPA 空间里的潜空间 WAM，通过共享预测器把潜空间转移预测与连续动作生成耦合起来。

JEPA-WAM 预测一个空间结构化的联合当前-未来目标，捕捉当前与未来观测之间任务共享的视觉时间结构，同时保留稠密的 patch 级对应关系。转移监督通过共享预测器直接塑造骨干，动作预测的专用表示从同一骨干抽取。同样的设计也能实例化到预训练 VLA 策略里而不动其原有感知与动作通路。在 LIBERO-Plus 上，JEPA-WAM 取得 79.2%，是无大规模机器人策略预训练方法里的最好成绩；其 π0.5 实例化达到 86.3%，全场最好。RoboTwin 2.0 与真实世界双臂操作实验进一步展示了视觉与空间偏移下的强泛化。

## 论文主线

![[papers/images/lin2026jepa-wam/page2_figure2_render.png|560]]

**Figure 2 潜空间 WAM 范式对比。** (a) 视频生成 WAM 用世界模型骨干直接接动作专家；(b) 专用潜动力学 VLA 在 VLM 骨干旁边挂对齐目标；(c) 用独立 LAM 预测潜未来再条件化动作；(d) 本文，V-JEPA 编码器接 LLM 预测器，转移预测与动作生成共享同一个预测器。

论文的问题设定从 WAM 的成本困境出发。VLA 的动作预测目标只隐式建模状态转移，分布偏移下不稳；视频生成式 WAM 显式建模未来却要迭代生成未来帧，部署成本高。潜空间 WAM 是折中，不生成帧、在表示空间做预测。但这条路要回答两个设计问题，这两个问题构成全文的骨架。

一个是预测目标学什么。已有做法要么复用视频生成器的中间特征（为迭代生成优化，不显式表示状态变化），要么把未来观测压成少量潜 token 或子目标（丢细粒度空间结构）。JEPA-WAM 的答案是在 V-JEPA 2.1 空间里构造「联合当前-未来目标」，把 $O_t$ 和 $O_{t+\delta}$ 沿时间维堆叠后让冻结编码器一起编码。这个目标表示的是转移而不是绝对未来，强调哪些区域稳定哪些在变、局部物体与空间关系怎么演化，同时保留稠密 patch 结构不做池化。V-JEPA 的管元设计在这里帮了大忙，双帧输入正好产出与单帧相同的空间网格，目标和当前表示天然逐 patch 对应。

另一个是预测监督怎么接进动作生成。已有做法要么把预测的未来表示当额外上下文喂给动作模块（动作模块暴露在冗余未来信息里），要么在策略旁边挂独立预测目标或潜动力学模块（对动作表示的影响很弱）。JEPA-WAM 的答案是共享预测器，一次前向里 Qwen2.5-0.5B 既在视觉 token 位置输出用于预测联合目标的 $Q^{wm}_t$，又在动作占位符位置输出条件化动作专家的 $C_t$。转移监督直接更新产生动作表示的同一个骨干，但动作专家不必消费完整的预测转移表示。部署时预测分支整个摘掉。

第三个卖点是可迁移性，同一套联合目标监督可以加到预训练 π0.5 上（附加未来 token 加轻量对齐头），不动原有感知与动作通路，LIBERO-Plus 从 84.5 提到 86.3，真机从 77.5/72.5 提到 90.3/84.7（ID/OOD）。

## 3 Method / 目标与监督位置的两个答案

### 3.1 V-JEPA 空间与联合目标

![[papers/images/lin2026jepa-wam/page3_figure3_render.png|760]]

**Figure 3 JEPA-WAM 总览。** 冻结 V-JEPA 编码器构造空间结构化的联合当前-未来目标做潜空间转移预测。共享预测器从当前观测学任务共享的视觉时间结构，后续动作表示整合视觉上下文与任务指令去条件化动作专家。目标分支只在训练期使用。

当前视觉表示，各相机视角独立过冻结 V-JEPA 编码器，按固定相机顺序拼接

$$
Z_t=\mathrm{Concat}_{v\in V}\,E_J(O^v_t)\in\mathbb{R}^{N_{vis}\times d_J}
$$

不做空间池化，每视角是 24×24 网格的 1024 维 patch 特征（ViT-L/16，输入 384×384）。

联合目标，训练时每个当前观测配一个 $\delta$ 步之后的未来观测，逐视角沿时间维堆叠后联合编码并停梯度

$$
Y_{t,t+\delta}=\mathrm{Concat}_{v\in V}\,\mathrm{sg}\bigl[E_J(\mathrm{Stack}_{time}(O^v_t,O^v_{t+\delta}))\bigr]\in\mathbb{R}^{N_{vis}\times d_J}
$$

V-JEPA 2.1 的视频分词器把每两帧组成一个时间管元，双帧输入产出与单帧相同的空间网格，所以 $Y_{t,t+\delta}$ 与 $Z_t$ 逐 patch 对应。$\delta$ 按基准设，LIBERO 取 31，RoboTwin 取 50，轨迹尾部截到最后一帧。

联合目标与「只编码未来帧」的区别是全文的立论点。future-only 目标孤立地表示未来观测，联合目标让预训练编码器同时看到两个时间端点，编码的是它们的视觉关系，哪些区域稳定、哪些在变、局部物体与空间关系怎么跨时间演化。不要求重建一个完整或唯一的未来，保留 patch 组织不压缩。

### 3.2 共享预测器

视觉接口对齐先做一步，两层投影器 $P_{vis}$（1024→896→896，GELU）把 V-JEPA 特征映到 Qwen 输入空间，按 Prismatic 的单阶段配方在 LLaVA v1.5 上微调投影器与完整 Qwen2.5-0.5B 两个 epoch。之后的机器人策略训练里，V-JEPA、投影器、Qwen 基座全部冻结，只训 Qwen 的 LoRA 适配器（秩 32、缩放 64、dropout 0.1）、转移预测头和动作专家。

共享预测器一次前向处理三段输入

$$
(Q^{wm}_t,\ C_t)=F_\theta\bigl(P_{vis}(Z_t),\ \ell,\ P_{act}\bigr)
$$

视觉 token 位置的隐状态 $Q^{wm}_t$ 保留相机与空间顺序，用来预测联合目标；64 个动作占位符的隐状态 $C_t$ 聚合前文视觉与任务上下文，用来条件化动作。转移预测头 $G_\phi$（896→2048→1024 逐 token MLP）把 $Q^{wm}_t$ 映回 V-JEPA 空间，损失是逐 patch 余弦距离

$$
\mathcal{L}_{wm}=\frac{1}{BN_{vis}}\sum_{b,n}\Bigl(1-\cos\bigl(\hat Y^{(b)}_{t,t+\delta,n},\,Y^{(b)}_{t,t+\delta,n}\bigr)\Bigr)
$$

动作侧是 StarVLA 风格的 DiT-L（16 层）条件流匹配，输入噪声动作、流时间 $\tau$（Beta 调度，$\alpha=1.5,\beta=1.0$）、本体状态 $s_t$、32 个可学习未来 token 与 $C_t$，LIBERO 用速度预测目标

$$
\mathcal{L}_{act}=\mathbb{E}_{\epsilon,\tau}\bigl[\lVert A_\psi(a_\tau,\tau,s_t,C_t)-(a-\epsilon)\rVert^2_2\bigr]
$$

RoboTwin 改用 x 预测（直接预测干净轨迹），作者说更长的双臂动作块下训练更稳，引 JiT 佐证。

### 3.3 联合训练与部署

$\mathcal{L}=\mathcal{L}_{act}+\lambda_{wm}\mathcal{L}_{wm}$，$\lambda_{wm}=0.5$，两个损失都更新共享预测器。60K 步、批量 128、8 卡 FSDP BF16。部署时目标分支与预测头全部移除，只剩单帧 V-JEPA 编码、投影器、共享预测器、动作专家，动作块用 4 步 Euler 积分生成。RoboTwin 设定下单次推理 85ms（11.76Hz）。

### 3.4 迁移到预训练 π0.5

做法受 VaLR 启发。往 π0.5 的 VLM 前缀追加 64 个可学习未来 token，取其输出隐状态（64×2048）排成 8×8 粗网格，LayerNorm 加 MLP（2048→2048→1408）后双线性上采样到 24×24，与冻结 V-JEPA ViT-G 的联合目标逐 patch 对齐。$\lambda_{wm}$ 前 1K 步线性升温到 0.1。注意力掩码是这个迁移的关键设计，未来 token 可以看图像与语言前缀，动作 token 被禁止看未来 token，辅助分支只通过共享 VLM 骨干起作用，原动作通路完全不变。推理时未来 token 留在前缀里但动作看不到它们，延迟只涨 1ms（54.05 到 55.12ms）。

### 关键证据 / 图表 / 公式

Eq. 2 的联合编码构造是最核心的一行，管元恰好保持网格对应是它可行的前提。Eq. 3 里 $Q^{wm}_t$ 与 $C_t$ 的分工配合消融 (f) 是「共享骨干但隔离读出」这个设计的证据。3.4 的注意力掩码设计决定了迁移版的收益只能来自骨干被塑造，排除了「动作偷看未来预测」的解释。

## 4 Experiments / 三个问题三组证据

| f. Full hidden | 73.1 | 去掉动作占位符，动作专家看全部隐状态 |
| JEPA-WAM | 79.2 | 完整配置 |

这张表把三个设计问题逐一定量了。表示本身值 3.8 个点（73.2 到 77.0），V-JEPA 潜空间对相机、光照、噪声扰动天然更稳。目标构造上，联合编码 79.2 对未来单编 77.3 对端点差分 70.9，联合编码不是「给出结果状态」也不是「显式做差」能替代的。空间结构值 4.5 个点（对 iREPA 变换的 74.7）。监督位置上末层比中间层好 2.7 个点。动作读出的隔离值 6.1 个点（对 Full hidden 的 73.1），直接共享转移表示会造成两个目标互相干扰，专用占位符既保住共享骨干上的转移监督又给动作一个干净读出。

### 4.3 附录 C.2 的探针三连

端点差分掉到 70.9 这个大幅退化促使作者做了一组冻结表示探针，回答「联合编码到底多存了什么」。设置是 RoboTwin Clean 20 任务 1000 episode，岭回归线性探针，episode 不相交划分，1000 次配对 bootstrap 估计不确定度。

固定未来帧的时间差解码。对固定锚点 $O_f$ 构造六种时间差（0 到 50 帧）的配对，六分类探针从冻结表示预测时间差。future-only 按构造无信息（16.7% 即随机水平），端点差分 47.0%，联合目标 67.2%，配对提升 20.1 个点（95% CI [18.3, 21.9]）。两个表示都能看到两个端点，差距只能来自「关系怎么被表示」。

未见时间差泛化。数值回归探针只在 {0,20,40} 上训练、在 {10,30,50} 上测，联合目标 MAE 8.88 帧对端点差分 13.32 帧。时间信号不是死记类别，是结构化的。

去掉端点位移后的轨迹结构。把 14 维机器人状态轨迹减去两端点间的直线插值，探针只看两个视觉端点预测 49×14 的残差轨迹。联合目标 $R^2$ 0.582 对 0.485（+0.097，CI [0.082, 0.112]），49 个中间时间步全部占优。联合表示里的额外信息不止「起点终点在哪」，还包含区间内轨迹怎么偏离直线。

反向对照做得很诚实。直接预测端点位移 $\Delta s=s_{t+50}-s_t$ 时端点差分反而略好（0.740 对 0.718，差异显著）。作者的解读是两种表示各有分工，特征做差是一阶端点变化的强表示，联合编码保的是时间关系与区间内结构。这个「联合目标并非全面占优」的负结果让整组探针可信度上了一档。

空间诊断（定性补充），用匹配的静态双帧控制（$\mathrm{Stack}(O_t,O_t)$）对比动态联合目标，逐 patch 表示变化与 RGB 变化的中位相关 0.279，中等偏弱。作者自己定位成「支持空间结构化转移信息」的诊断，不是精确运动定位的证据。

## 方法细节

架构规格集中列一下。V-JEPA 2.1 ViT-L/16 冻结，384×384 输入，每视角 24×24×1024；投影器两层 MLP 1024→896→896；预测器 Qwen2.5-0.5B（隐维 896），策略训练期只动 LoRA（r=32，α=64，dropout 0.1）；转移头逐 token MLP 896→2048→1024；64 动作占位符；动作专家 16 层 DiT-L 流匹配，带本体状态与 32 个可学习未来 token。VL 初始化按 Prismatic 单阶段在 LLaVA v1.5 上训 2 epoch（AdamW，lr 2e-5，批量 128）。

策略训练，$\lambda_{wm}=0.5$，AdamW 峰值 lr 2e-4 余弦衰减到 1e-5，3% 预热，零权重衰减，梯度裁剪 1.0，BF16 FSDP，8 卡批量 128，60K 步。LIBERO 配置为主相机加腕部相机、7 维动作、块长 8、$\delta=31$；RoboTwin 为一外部加两腕部相机、14 维双臂动作、块长 50、$\delta=50$、x 预测。

π0.5 迁移配置，64 未来 token、8×8 网格上采样到 24×24、对齐 ViT-G 目标、$\lambda_{wm}$ 一千步升温到 0.1、动作 token 对未来 token 的注意力被掩掉。

部署只需当前观测与指令，4 步 Euler 出动作块，转移分支不执行。

## 实验设置、数据集、基线、指标

四个评测场。LIBERO 四套件联合训练、原环境测 ID；LIBERO-Plus 零微调直接测七类扰动；RoboTwin 2.0 二十任务 Clean 训练、Clean 与 Random 双设定评测；真机 AgileX Cobot Magic 五任务、每任务 100 演示、ID/OOD 各 10 rollout、归一化完成分。基线按有无大规模机器人策略预训练分组，无预训练组有 Diffusion Policy、ACT、DP3、VLA-Adapter、RoVLA、ResVLA、Fast-WAM，预训练组有 RDT-1B、π0、π0.5、VLA-JEPA、Motus、PokeVLA、ABot-M0、Cosmos-Policy、Being-H0.7。指标是成功率（仿真）与归一化完成分（真机），另报推理延迟。

## 主要结果、消融或对比

LIBERO ID 96.7（0.5B 追平 2B 基线），π0.5 加目标 97.8 组内第一。LIBERO-Plus 79.2 无预训练组第一（差预训练的 VLA-JEPA 仅 0.3），π0.5 加目标 86.3 全场第一。RoboTwin Clean 79.9 / Random 36.9，Random 追平预训练 π0.5；π0.5 加目标 Clean +9.2 但 Random 仅 +0.3。真机 JEPA-WAM 59.8/54.2 对 π0 的 51.8/22.5，π0.5 加目标 90.3/84.7 对 77.5/72.5。消融显示 V-JEPA 表示 +3.8、联合目标对未来单编 +1.9 对端点差分 +8.3、patch 结构 +4.5、末层监督 +2.7、动作读出隔离 +6.1。推理 85ms，π0.5 加目标仅 +1ms。

## 局限与可追问点

作者自陈一条，转移目标学的是与语言基本无关的任务共享视觉时间结构（局部变化、物体与空间关系演化），同一观测在不同指令下通向差异很大的转移时表达力不足，语言条件化或多模态转移目标留作未来。

我自己的追问。

语言短板不只是「未来方向」，它已经在数字里了。LIBERO-Plus 语言扰动类 JEPA-WAM 只有 68.2，比 0.5B 的 VLA-Adapter（74.6）还低，是它七类里唯一垫底的类。语言无关的转移目标加只在 LLaVA v1.5 上过了两个 epoch 的轻量 VL 对齐，语言鲁棒性差是这个设计的直接代价，论文没把这两件事连起来说。

π0.5 迁移版的收益结构值得追。LIBERO-Plus 上涨 1.8、真机涨 12.8，RoboTwin Random 只涨 0.3。三个场的收益差这么多，哪个变量在起作用（扰动类型、数据规模、任务难度）没有分析。真机那 12.8 有 10 rollout 部分得分制的方差问题，说实话也不确定它能不能稳定复现。

「共享预测器优于独立世界模型」这条主张的直接证据其实不足。与 VLA-JEPA 的对比里骨干参数（0.5B 对 2B）和预训练（无对有）都不同，不是受控实验。真正受控的只有 Full hidden 消融，它证明的是「共享骨干下动作读出要隔离」，不是「共享优于分离」。要坐实这条得做一个同规模的独立预测器对照，论文没做。

$\delta$ 的选择没有扫描。LIBERO 31、RoboTwin 50，都是每基准一个定值，转移目标对时间跨度的敏感性完全未知，而探针恰恰显示表示里编码了时间差信息，$\delta$ 大概率不是无关变量。

七类扰动的分类明细里还有一个没人解释的现象，π0.5 加 JEPA 目标后相机类从 69.4 掉到 66.0。涨的类（机器人 +6.7）和跌的类（相机 −3.4）说明这个辅助目标在重排 π0.5 的鲁棒性分布，不是均匀增益，机制值得画出来。

## 与当前库的连接

跟 [[@gao2026fast-leworldmodel]] 是最直接的对话。Fast-WAM 问世界动作模型要不要测试时的未来想象，JEPA-WAM 的答案更彻底，训练时把转移监督压进骨干、部署时预测分支整个摘掉，85ms 的推理就是这个答案的价格标签。Table 1 里 Fast-WAM（5B，97.6）也是它 LIBERO 上的直接对照。

跟 [[@zhang2026lingbot-va2]] 构成潜空间对视频生成两条 WAM 路线的对照。LingBot-VA 2.0 走视频动作世界模型加实时控制，JEPA-WAM 论证的是不生成帧也能拿到转移建模的好处，两篇放一起是「显式未来到底值多少钱」的正反方。

跟 [[@feng2026wam-ttt]] 和 [[@qian2026wam-rl]] 同属 WAM 谱系但阶段不同，那两篇做部署期与后训练期的适配，JEPA-WAM 做的是预训练结构本身，读 WAM 线可以按「结构、后训练、部署适配」排这三篇。

跟 [[@fu2026lingbot-vision]] 在「具身该用什么视觉表示」上直接相关。消融 (a)(b) 那 3.8 个点是 V-JEPA 对 DINOv2+SigLIP 的直接比分，做表示选型时这是可引用的数据点。

跟 [[@liu2026last0-latent-spatio-temporal]] 都在潜空间里做时空结构，LaST₀ 把它做成推理链，JEPA-WAM 把它做成监督目标，潜空间时间结构的两种用法。

跟 [[@yang2026dreamtrajectory]] 在「世界模型信号怎么进策略」上互补，DreamTrajectory 用轨迹引导对齐，JEPA-WAM 用共享骨干的辅助损失，前者作用在输出侧后者作用在表示侧。

## 精读路线 / 为什么需要回看

第一遍看 Figure 2 加 Figure 3，把四种潜空间 WAM 范式和本文位置摆清楚，再看 Table 2 主表加分类明细，把 79.2/86.3 的口径和语言类短板一起记住。

第二遍看 3.1 的联合目标构造和 Table 4/6 消融，联合编码对端点差分那 8.3 个点是全文的证据重心，配合附录 C.2 的三个探针把「联合编码保了什么」读透，那组分析的实验设计本身就值得学。

第三遍按需看 3.4 的 π0.5 迁移配方，未来 token、上采样对齐、注意力掩码三件套是可以直接搬走的工程方案，成本是每步 1ms。

需要回看的场景有几个。给现成 VLA 加辅助世界建模监督时回看 3.4 和附录 A.4，那是一份完整配方。做视觉表示选型时回看消融 a/b 的 3.8 个点。争论「潜空间 WAM 该不该保空间结构」时回看 iREPA 消融的 4.5 个点。设计任何双目标共享骨干的模型时回看 Full hidden 消融，读出隔离那 6.1 个点是通用教训。评估「转移监督对重度域随机化有没有用」时回看 RoboTwin Random 那 +0.3，别把 LIBERO-Plus 的故事外推过去。
