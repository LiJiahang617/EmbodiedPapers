## 摘要

本文提出新的机器人基础模型 **π0.7**，能在广泛场景下有强"开箱即用"表现：在**未见环境**里跟随多样语言指令（含多阶段厨房家电任务）、**零样本跨本体泛化**（如让一个从未训练过叠衣的机器人叠衣）、并**开箱**操作浓缩咖啡机，达到与更专门的 RL 微调专家相当的水平。核心思想是训练时用**多样上下文条件化**：prompt 里不只有"做什么"的语言命令，还有描述"怎么做/以何策略做"的额外多模态信息（任务表现的元数据、子目标图）。这让 π0.7 能用**非常多样**的数据——示范、可能次优的（自主）数据含失败、以及非机器人来源的数据。在最难的任务上，π0.7 匹配甚至超过专门的 RL 微调模型。

## 论文主线

一句话锚定：**不改架构、不发明新组件，而是给每条训练样本配上"详细多模态上下文"（子任务文本 + 子目标图 + 回合元数据 + 控制模式），从而把示范/失败/自主/非机器人等异构数据统一喂给一个 VLA，解决"多样数据被平均成次优"的老问题，并让模型涌现出组合泛化、跨本体零样本、开箱即用的通用能力。**

![[papers/images/intelligence2026pi07-steerable-generalist-robotic/fig1_overview.png|780]]

**Figure 1 / 总览。** 左（Robot Data：示范 + 自主数据）与右（Non-Robot Data：多模态网络数据 + 第一人称人类数据）→ **TRAINING**：每条样本配 Language Instructions + Subgoal Images + Episode Metadata（质量/长度）→ **π0.7 VLA**（PROMPT + action expert）→ **INFERENCE**：High-Level Policy 给子任务、World Model 生成子目标图、Desired Metadata 指定质量/速度 → 无微调开箱即用（含专家级灵巧、跨本体迁移）。

论证链条：

1. **问题定位**：基础模型的通用性来自"从大而多样数据里涌现的组合泛化"（LLM 能组合技能解新题）。但机器人 VLA 至今**连流畅执行训练过的指令都常需任务特定微调**，更难组合技能解新任务。
2. **为什么天真做不行**：想用多样 + 次优数据（不同策略/不同质量/失败/自主/非机器人），但**天真训练会把不同模式平均**→次优结果。而且"什么决定成功/熟练"往往**语言说不清**（如"叠得干净的 T 恤"的具体样子）或很微妙（回合整体质量）。
3. **解法**：给每条样本加**详细上下文标注**——不只"做什么"，还有"怎么做"，并用多模态条件化信号提供给模型。prompt = 更表达性的语言 + 策略元数据 + 子目标图。训练时随机丢弃各成分 → 测试时可用任意子集。这样能**消解多样数据的歧义、从次优行为学习而不掉性能、并跨指令/本体/环境广泛泛化**。
4. **模型**：5B（4B Gemma3 VLM + MEM 视频历史编码器 + 860M flow-matching 动作专家），建于 π0.6-MEM；子目标图由 BAGEL 初始化的轻量世界模型生成；子任务由高层策略给出。KI recipe + FAST。
5. **涌现能力**：开箱即用（咖啡/叠衣/换垃圾袋/折箱/削菜，匹配/超过专家 RL 微调）、指令泛化（未见厨房卧室，> π0.5/π0.6）、零样本跨本体（未训练的机器人叠 T 恤，匹配专家遥操首次尝试）、组合泛化（空气炸锅等新家电）。消融证明**元数据 + 自主评测数据都是关键**（去掉任一都掉，尤以吞吐量差距明显）。

## 逐节精读

### §I–III 动机与形式化

本节把"通用性=组合泛化"作为北极星，并诊断机器人域的两个卡点：**数据多样但被平均**、**成功要素难以语言表达**。VLA 形式化（Eq 1）沿用 flow matching 动作专家（优化近似下界）+ KI recipe（VLM 用 FAST 离散 token 稳定监督、动作专家梯度不回流 VLM）。关键概念：每条样本带上下文 Ct，传统只放语言 ℓ，本文把它扩成多模态。

### §V 多样化 prompt —— 全文方法核心

- **(A) 子任务指令 `ℓ̂`**：沿用 π0.5，在整体任务 ℓ 之外加中层语义子任务文本（"打开冰箱门"）。运行时可由学习到的高层策略 / 人 / 世界模型给出，支持**逐步语言 coaching**（口头教模型做新任务，再把 coaching 数据微调成高层策略）。
- **(B) 子目标图 `gt`**：多视角"近未来期望画面"，补语言说不清的执行细节（"打开冰箱门"没说怎么抓把手）。由世界模型 `gψ`（从 **BAGEL**——14B MoT 图像理解/编辑/生成模型初始化，SuSIE 式）生成，吃网络 + 非机器人视频数据，把语义/物理概念迁进 π0.7。训练目标是 flow matching 损失。子目标图让动作预测**变成"逆动力学"问题**（推当前→未来帧之间的动作），故只给 25% 样本加子目标图；其中 30% 丢子任务文本（视觉子目标可替代）。
- **(C) 回合元数据 `m`**：**overall speed**（回合步数，500 步分箱；快常等于高质量少犯错）、**overall quality**（1–5 分）、**mistake**（该动作段是否犯错，人工粗标）。让模型把次优/失败数据正确"归因"，运行时可指定"高速/高质量/不犯错"。
- **(D) 控制模式 `c∈{joint,ee}`**：文本标识，训练含两种、运行时按任务选。不做 dropout。
- **(E) dropout**：metadata 整体丢 15% + 每分量额外 5%；控制模式不丢。→ 测试时任意子集灵活可用。

**关键证据 / 图表**：Fig 1（数据→上下文→VLA→推理，已嵌入）、Fig 2（5B 架构：VLM + MEM 编码器 + 动作专家 + 多模态上下文）、示例 prompt（"Task: peel vegetables. Subtask: pick up the peeler. Speed: 8000. Quality: 5. Mistake: false. Control Mode: joint."）。

### §IX 实验 —— 涌现能力的证据

- **开箱即用（IX-A）**：无任务特定后训练即执行咖啡机、叠衣、换垃圾袋、折箱、削菜；与建在 π0.6 上的 **SFT 专家**对比，π0.7 匹配、有时 throughput 更高。
- **消融（Fig 7）**：π0.7 vs **π0.7(no metadata)** vs **π0.7(no eval data)**——π0.7 全面胜出，**吞吐量差距最明显**；说明元数据（区分数据质量）与自主评测数据（含失败/纠偏）**都对强性能关键**。
- **指令泛化**：4 组指令、未见厨房/卧室，π0.7 显著超 π0.5 与 π0.6，指令跟随成功率高。
- **子目标图（Fig 11）**：条件化生成子目标图（π0.7(GC)）进一步提升语言跟随/泛化。
- **跨本体**：研究"零样本跨本体是否为涌现属性"——能把叠 T 恤等灵巧技能直接迁到未训练该任务的机器人，匹配专家遥操首次尝试。

## 方法细节（实现口径）

- **模型（§IV/VI-B）**：约 5B——4B Gemma3 VLM（含 400M 视觉编码器）+ MEM 视频历史编码器（时空压缩、定长 token）+ 860M flow-matching 动作专家。建于 π0.6-MEM。
- **世界模型**：BAGEL（14B MoT）初始化，SuSIE 式；生成多视角子目标图。高层策略同架构。
- **训练技巧**：KI recipe + FAST token；子目标图仅 25% 样本；metadata dropout 15%+5%；控制模式不丢。
- **数据**：多机器人（静态/移动、单/双臂、lab/home/in-the-wild）示范 + 自主评测/人类干预 + 开源机器人数据集 + 第一人称人类视频 + 网络非机器人数据。

## 实验设置、数据集、基线、指标

- **平台**：多种机器人（含 UR5e 用于跨本体测试），带前视 + 每臂腕部相机。
- **任务**：咖啡机（浓缩）、叠衣、换垃圾袋、折箱、削菜等长时程灵巧任务；"Robot Olympics" 系列；指令泛化 4 组、未见厨房/卧室。
- **基线/消融**：π0.5、π0.6、π0.6-SFT 专家、**π*0.6（RL 微调专家）**；π0.7(no metadata)、π0.7(no eval data)、π0.7(GC)。
- **指标**：成功率、**throughput（successes/hour，归一化）**、指令跟随成功率。

## 主要结果、消融与对比

- **开箱即用匹配/超 RL 专家**：在 π*0.6 发布用过的任务（含换垃圾袋）上，π0.7 无任务特定后训练即达高性能，throughput 有时超专家。
- **消融（Fig 7）**：去元数据、去自主评测数据都全面掉点，**吞吐量差距最大**——两者都关键。
- **指令泛化**：> π0.5/π0.6，未见厨房卧室高成功。
- **子目标图（Fig 11）**：GC 条件化显著改善。
- **跨本体/组合**：零样本叠 T 恤到新机器人匹配专家遥操首试；prompt 组合出空气炸锅等新任务。
- **协同**：多样数据 + 详细上下文有强协同——混质数据/非标准来源不掉性能，且详细上下文下多样数据反而提升性能。

## 局限与可追问点

（本文以能力展示为主，局限散见正文）
1. **依赖大量人工标注**：详细语言、质量/犯错元数据、子任务都需人标（虽可粗标）——规模化标注成本与噪声如何？能否自动标（用 VLM/价值函数）？
2. **子目标图依赖 BAGEL 世界模型**：生成质量/幻觉直接影响下游；世界模型错了怎么办？
3. **"涌现/组合泛化"多为选例**：缺乏系统化覆盖率评估；哪些组合能泛化、哪些不能，边界不清。
4. 与 π*0.6 的关系：π0.7 把**自主/RL 数据当作一种数据源**并用元数据条件化，而 π*0.6 是**显式 RL 优化**——两条路线（上下文条件化 vs 优势条件化 RL）在什么任务上各自更优？
5. 跨本体"匹配专家遥操首试"是相对弱的基准；真正达到专家熟练度还差多远？

## 一句话总结

Physical Intelligence **提出并展示** π0.7：不改架构，而是给每条训练样本配上"子任务文本 + 生成式子目标图 + 回合元数据（速度/质量/犯错）+ 控制模式"的多模态上下文并随机 dropout，从而把示范、含失败的自主数据、非机器人数据统一喂给一个 5B VLA，解决"多样数据被平均成次优"的问题——由此涌现出开箱即用的专家级灵巧、未见环境指令泛化、零样本跨本体迁移与组合泛化，是与 π*0.6（RL 从经验学）互补的"上下文条件化"路线代表作。
